# Skills Implementation Matrix

The brief asks for a matrix of "all 24 skills." This session's actual environment has
**26** skills available, not 24 — listed below honestly rather than forced to match the
brief's number. Several are irrelevant to a healthcare SaaS build (e.g. a Saudi
lead-research skill, a blog-publishing skill, keybinding config) and are marked
**N/A** rather than stretched to look used, per the instruction not to build a fake
product — that applies to this document too.

Important distinction: these are tools *I* (the assistant) use while building and
documenting the project. They are not runtime features of the shipped app — the app's
own PDF generation (prescriptions), chart rendering (analytics dashboards), etc. are
application code (e.g. a PDF library, a charting library), tracked in ROADMAP.md phases
8 and 11, not this list.
